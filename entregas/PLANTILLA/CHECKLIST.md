# Lista de verificación antes de entregar

- [ ] Registré y commiteé las predicciones antes de ejecutar.
- [ ] Diferencié error de compilación, lint, panic, excepción y reporte de sanitizer.
- [ ] No traté el comportamiento indefinido de C como un resultado estable.
- [ ] Analicé al menos un límite de la seguridad de memoria (RefCell, unsafe o fuga).
- [ ] La conclusión menciona contexto, trade-offs y evidencia, y incluí versiones y comandos.
